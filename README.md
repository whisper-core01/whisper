# WHISPER

**Local-sovereign communication and storage architecture.**

WHISPER is built around one rule:

> **External input is data, never authority.**

WHISPER does not rely on external RPC endpoints, bridges, validators, cloud infrastructure, external entropy sources, or remote truth providers.

Security-critical derivation, validation, boot authority, and state transitions remain local.

---

## Why WHISPER exists

Modern distributed systems often fail when an external dependency silently becomes an authority.

A bridge, RPC endpoint, relay, validator, phone, cloud service, or external oracle can become a hidden trust root. When that trust root fails, the whole system can inherit a false state.

WHISPER takes the opposite approach:

```text
transport != trust
signal != authority
external input != external truth

External bearers may move opaque packets.

They never validate, authorize, unlock, derive, or define system state.

Current cryptographic doctrine

The RotorMachine is not used as a cipher.

It is a local sovereign derivation and structural diversification engine. It produces internal material, rotation contexts, offsets, and transformation schedules.

Serious data protection relies on standard primitives:

local seed
+ internal state
+ session context
+ fragment context
+ cycle context
        ↓
RotorMachine
        ↓
internal key material
        ↓
HKDF-SHA-256
        ↓
ChaCha20-Poly1305 / XChaCha20-Poly1305 AEAD
        ↓
ciphertext + authentication tag

In short:

RotorMachine -> HKDF-SHA-256 -> AEAD

The confidentiality and authentication of serious data such as Vault entries, fragments, channels, and session payloads rely on standard AEAD cryptography, not on custom encryption.

What WHISPER is

WHISPER is:

a local-sovereign communication architecture;
a fragmented encrypted storage and transport model;
a no-external-truth security model;
a Wasm-sandboxed execution architecture;
a system for opaque packet transport over untrusted bearers;
a framework for local derivation, fragmentation, validation, and degraded-mode resilience.
What WHISPER is not

WHISPER is not:

a blockchain;
a bridge;
a DeFi protocol;
a cloud service;
a Tor replacement;
a claim of perfect anonymity;
a custom cryptographic cipher;
a system that trusts external validators;
a system that imports remote truth into its security core.

Security claim

WHISPER claims the following:

WHISPER minimizes external trust by keeping security-critical derivation, validation, boot authority, and state transitions local. External bearers transport opaque packets and never act as authorities. Serious cryptographic confidentiality and authentication rely on standard AEAD primitives and HKDF, while the RotorMachine provides local sovereign derivation and structural diversification.

WHISPER does not claim absolute security, perfect anonymity, or protection against a fully compromised host.
