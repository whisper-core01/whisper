# WHISPER Simulation Schemas

These schemas define the initial machine-readable output contract for Phase 2.

Status: v0.5.0 minimal valid schemas.

They are intentionally small and will be expanded during:

- v0.6.x simulator implementation
- v0.7.x baseline comparison
- v0.8.x simulation reporting

The purpose of v0.5.0 schemas is to make the repository reproducible and machine-readable without over-designing formats before the simulator exists.
