# GRANT_REVIEW_POSITIONING.md

## Positioning WHISPER for different reviewers

WHISPER Remote Nerve should not be framed for only one funder.

It can be positioned as an open infrastructure research project with different emphasis depending on the reviewer.

---

## NLnet angle

Primary signals:

```text
open source
public-interest infrastructure
security boundaries
responsible threat model
reproducibility
clear roadmap
```

Suggested summary:

```text
WHISPER Remote Nerve is a tested experimental MVP framework for exploring
resilient communication architecture. It is openly documented, explicitly
non-overclaiming, and ready for a simulation and validation phase.
```

---

## Protocol Labs angle

Primary signals:

```text
decentralized systems
adversarial topology simulation
machine-readable research artifacts
resilience metrics
libp2p/IPFS compatibility potential
```

Suggested summary:

```text
WHISPER Remote Nerve is a tested experimental framework for studying whether
structural divergence can improve resilience in decentralized communication
pipelines under adversarial topology conditions.
```

---

## Shared core

Both audiences should see:

```text
tested MVP
threat model
whitepaper
roadmap
simulation plan
reproducibility baseline
explicit non-security claims
```

---

## Avoid

Do not claim:

```text
secure protocol
anonymous network
Tor replacement
libp2p replacement
Reticulum implementation
production-ready transport
```

---

## Use

Use:

```text
tested experimental framework
structural-divergence research
simulation-ready architecture
grant/research review baseline
```
